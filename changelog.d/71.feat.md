Alerting now supports more than Slack: `--alert-format`/`spec.alerting.format` selects between `slack` (default, unchanged), `teams` (Microsoft Teams Incoming Webhook), `pagerduty` (Events API v2, opens/updates an incident), or `custom` (a user-supplied Go `text/template`, for any destination that isn't one of the built-in three). `slackWebhookUrl`/`--slack-url` keep working exactly as before. See [Alerting](https://joao00001.github.io/pg-regression-radar/alerting/) for the full field/flag reference and the custom template's available fields.
